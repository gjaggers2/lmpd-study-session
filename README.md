# LMPD Study Session

Mobile-first installable PWA for studying the Louisville Metro Police Department Standard Operating Procedures.

Live: https://gjaggers2.github.io/lmpd-study-session/

- Source: official LMPD SOP PDF https://www.lmpd.gov/DocumentCenter/View/615/Standard-Operating-Procedures-PDF (linked from https://www.lmpd.gov/35/LMPD-Transparency). PDF last modified 2026-09-18, 1,002 pages, retrieved 2026-10-11.
- 208 SOPs in 12 chapters, extracted with poppler (text-based PDF, no OCR needed).
- 404 multiple-choice questions written from the SOP text, each with an explanation and SOP section citation.
- Library, Listen (device TTS plus pre-generated MP3 podcast audio made with edge-tts), Notes, Quiz.

Study aid only. Always defer to the official current SOP.
